Issue workspace — one screen, two modes (use the new / edit switch top right)

1Open empty, already half-filled

N opens the same screen in new mode, with metadata copied from the last issue: year, country, stamp type, print, printer, artist, paper, perforation.

2Type the differential fields

Name, date, total printed, market values. Everything marked ⟲ came from the previous issue.

3Generate the rows

rows = 8 creates 8 stamp rows that inherit the issue values, so those cells never get typed.

4Auto-number the catalog codes

First edifil 2744 + Fill series numbers 2744–2751, keeping variant suffixes (2744a → 2744b).

5Only 4 columns of real work

Fast row mode leaves edifil, fesofi, face value and colors. Of the rest, only name, total printed and the two market values can differ per stamp (grey = same as the series, black = set here, ⟲ restores).

6One commit, then keep going

Ctrl ↵ creates issue + stamps in a single transaction. Next screen offers create another in 1987, metadata still loaded.

7Editing an existing series is the same screen

Flip to edit: identical metadata strip, identical grid, identical inheritance greys and fast row toggle. Only the top-bar actions (Clone, Delete) and the footer wording change.

8The buffer is what you review

The footer always shows the pending change set — "new issue + 8 stamps" or "12 changes not saved" — and commits it in one transaction.

9No separate editor to drift

One template, one grid module, one test suite, mode=new | edit. Every improvement lands in both flows at once.
